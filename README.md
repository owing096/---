# Air War — 基于 Qt 的双人飞机大战

一款使用 **C++ / Qt5** 开发的 2D 纵版滚动射击游戏（STG）。支持单人挑战、双人合作与双人对战三种模式，包含波次刷怪、Boss 战、道具系统与实时碰撞检测。

> 实习实训项目 · 作者：薛卜玮（2025141460023）

---

## 功能特性

- **三种游戏模式**：单人（Single）、双人合作（Co-op）、双人对战（VS）
- **完整游戏流程**：主菜单 → 游戏进行 → 结算界面，支持「再来一局 / 返回主菜单」
- **波次与 Boss 战**：每波敌机清空后刷新 Boss，击败后进入下一波，难度随波数递增
- **三类敌机**：杂兵机、精英机、Boss（多阶段弹幕：环形爆发 / 瞄准散射 / 螺旋弹）
- **道具系统**：击落敌机有概率掉落火力、炸弹、回血、护盾四种道具
- **滚动星空背景**：双缓冲图片循环滚动，滚动速度随波数加快
- **实时 HUD**：双方血量、得分、炸弹数、当前波数
- **碰撞检测**：基于 `QGraphicsItem::shape()` 的精确椭圆碰撞，保证判定手感

| 操作 | 玩家 1（蓝色） | 玩家 2（红色） |

## 玩法与数值

### 玩家

- 生命值 **100**，初始炸弹 **3** 枚，火力等级 **Lv.1 — Lv.4**
- 被击中后进入约 **1.5 秒** 无敌状态（机身闪烁），护盾可抵挡一次伤害，持续 **5 秒**
- 斜向移动做了归一化处理，八个方向速度一致

### 炸弹

清除屏幕上所有敌机子弹，并对全部敌机造成 **50** 点伤害，伴随全屏白闪特效。

### 敌机

| 类型 | 颜色 | 血量 | 击落得分 | 行为 |
| --- | --- | --- | --- | --- |
| 杂兵机 Basic | 红 | 20 | 100 | 直线下落，瞄准玩家射击 |
| 精英机 Elite | 橙 | 60 | 300 | 正弦轨迹移动，三向散射 |
| Boss | 紫 | 500 | 5000 | 多阶段弹幕：环形爆发、瞄准散射、螺旋弹 |

### 道具

| 道具 | 颜色 | 效果 |
| --- | --- | --- |
| Fire Power | 黄 | 火力等级 +1（最高 Lv.4，弹道变宽） |
| Bomb | 红 | 炸弹 +1（上限 3） |
| Health | 绿 | 恢复 30 点生命 |
| Shield | 蓝 | 抵消一次伤害，持续 5 秒 |

敌机被击毁有 **35%** 概率掉落道具。

### 计分

命中敌机 **10** 分；击落杂兵 / 精英 / Boss 分别 **100 / 300 / 5000** 分；VS 模式命中对手 **50** 分；使用炸弹对每架敌机额外 **20** 分。合作模式下击落得分由两人均分。

### 波次节奏

第 *n* 波敌机数量为 `8 + 2n`，刷新间隔随波数缩短（最低 30 帧），精英机出现概率随波数提高；波次内敌机清空后出现 Boss，Boss 被击败 3 秒后进入下一波。

## 构建与运行

### 方式一：CMake（推荐）

```bash
cd 项目源码

# 指定你的 Qt 安装路径后配置
cmake -S . -B build -DCMAKE_PREFIX_PATH="D:/Qt/5.14.2/msvc2017_64"

# 编译
cmake --build build --config Release

# 运行（Windows 下 windeployqt 会自动把 Qt DLL 拷到输出目录）
./build/Release/airwar.exe
```

> 也可以先把环境变量 `QTDIR` 指向 Qt 目录，`CMakeLists.txt` 会自动读取；不传 `CMAKE_PREFIX_PATH` 时给出明确的报错提示，而不是晦涩的 `Qt5_FOUND` 失败。

### 方式二：qmake

```bash
cd 项目源码
qmake airwar.pro
nmake        # 或 mingw32-make
```

### 方式三：Qt Creator

用 Qt Creator 打开 `项目源码/CMakeLists.txt`（或 `airwar.pro`），选择 Qt 5.14.2 套件后直接点击运行即可。

> 图片资源已通过 `assets.qrc` 编译进可执行文件，运行时不需要额外的 assets 目录。

## 技术要点

- **图形视图框架**：所有游戏对象继承自 `QGraphicsObject`，由 `QGraphicsScene` 统一管理并在每帧 `advance()` 中推进
- **游戏主循环**：`QTimer` 以约 **60 FPS**（`1000 / GAME_FPS`）驱动，逻辑与渲染解耦
- **状态机**：`GameState { MENU, PLAYING, PAUSED, GAME_OVER }` + `GameMode { SINGLE, COOP, VS }` 管理界面流转与规则差异
- **碰撞检测**：通过重写 `shape()` 返回椭圆 `QPainterPath`，用 `collidesWithItem()` 做精确判定，并用自定义 `type()` 做对象类型快速分派
- **信号槽解耦**：敌机击毁、玩家死亡、炸弹使用等事件以信号形式抛给场景，场景再更新分数、掉落道具与波次
- **资源管理**：贴图经 `assets.qrc` 打包进二进制，避免运行时路径依赖

## 已知限制

- 窗口固定为 900×1050，暂未做分辨率自适应
- `ESC` / `P` 目前直接返回主菜单，暂停遮罩层尚未实现
- 碰撞检测为 O(n²) 遍历，对象数量极大时可考虑四叉树优化

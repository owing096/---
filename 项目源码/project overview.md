1. 项目概述
本项目旨在使用Qt框架开发一款支持两名玩家在同一台计算机上进行实时游戏的2D纵版射击游戏（STG）。游戏在一个持续向上滚动的背景地图上进行，玩家各自控制一架战斗机，通过合作击落敌机或直接对战来获得胜利。项目将重点利用Qt的2D图形绘制系统（QPainter）和图形视图框架（QGraphicsView）来构建动态的游戏世界，并通过键盘事件处理和高效的碰撞检测算法实现流畅、火爆的空战体验。

2. 核心功能与技术实现
2.1 游戏主界面与流程控制
功能描述：

多场景界面： 实现清晰的游戏流程界面，包括：

开始菜单： 显示游戏标题、操作说明、最高分记录，并提供“单人模式”、“双人合作”、“双人对战”等选项。

游戏运行界面： 主战场视图，屏幕两侧或底部显示两名玩家的生命值、得分、炸弹数量等状态信息。

游戏结束界面： 显示“Game Over”或胜利信息，并展示最终得分。

动态滚动背景： 游戏背景（如天空、云层、地面景物）会持续不断地向上滚动，营造出飞机前进的视觉效果。

游戏状态管理： 使用**有限状态机（FSM）**来管理游戏的核心状态（MENU, PLAYING, PAUSED, GAME_OVER）及其转换逻辑。

(关联Qt技术：QMainWindow, QGraphicsView, QGraphicsScene, QPushButton, QTimer (用于背景滚动), 有限状态机设计)

2.2 核心游戏玩法与对象
功能描述：

双玩家飞机控制：

两名玩家通过键盘上的不同按键组（如玩家1: W/A/S/D + J键射击, 玩家2: 方向键 + 小键盘0射击）分别控制各自飞机的移动和开火。

飞机可以在屏幕下半区域自由移动。

武器与射击系统：

玩家飞机可以发射子弹，子弹沿机头方向直线飞行。

全屏炸弹（BOMB）： 每位玩家拥有数量有限的全屏炸弹，使用后可以清除屏幕上的所有敌机子弹并对敌机造成大量伤害。

游戏对象与精灵：

玩家飞机： 游戏主角，有生命值，被击中后会损失生命。

玩家子弹： 由玩家飞机发射，用于摧毁敌机。

敌机： 从屏幕上方以不同的路径和阵型出现，会向玩家发射子弹。敌机种类多样，如小型杂兵机、精英机、BOSS机。

敌机子弹： 类型多样，如普通子弹、散射弹、追踪弹等。

道具/Power-up： 击落特定敌机后会掉落道具，玩家拾取后可获得火力增强、增加炸弹、恢复生命等效果。

(关联Qt技术：QGraphicsItem (自定义飞机、子弹、道具等), QKeyEvent, 游戏主循环)

2.3 物理与碰撞检测
功能描述：

移动与边界限制： 玩家飞机的移动范围被限制在游戏窗口内，不能飞出屏幕。

碰撞效果判定： 系统需要实时检测大量的碰撞事件：

玩家子弹 vs 敌机： 击中后，敌机损失生命值，可能被摧毁。

敌机子弹 vs 玩家飞机： 击中后，玩家飞机损失生命值，可能触发短暂的无敌状态。

玩家飞机 vs 敌机： 相撞后，双方都损失大量生命值。

玩家飞机 vs 道具： 玩家拾取道具，获得增益效果。

(关联Qt技术：QGraphicsItem::collidesWithItem(), QPainterPath (用于更精确的碰撞形状))

2.4 游戏模式与关卡设计
功能描述：

单人模式： 一名玩家挑战不断出现的敌机，以获取更高分数为目标。

双人合作模式 (Co-op): 两名玩家共同迎战敌机，共享屏幕，但生命值和得分各自独立计算。考验团队配合。

双人对战模式 (VS):

屏幕左右分屏，或在同一屏幕进行。

玩家之间可以互相攻击，同时也要应对中立的敌机。

目标是击败对方玩家。

关卡与BOSS战：

游戏由多个关卡组成，每个关卡末尾会出现一个强大的BOSS敌人。

BOSS拥有复杂的攻击模式（弹幕）和多个阶段，需要玩家研究其行为模式才能击败。

(关联Qt技术：游戏逻辑脚本化/数据驱动设计)

3. 算法与数据结构深度优化（可选/提升）
敌机行为与弹幕算法：

运动路径： 敌机的飞行路径可以通过预设的贝塞尔曲线或正弦/余弦函数来生成，实现复杂的飞行动作。

弹幕设计： BOSS和精英敌机的弹幕（Bullet Hell）可以通过数学公式（如极坐标、螺旋线）来程序化生成，创造出华丽且有规律的弹幕图案。

碰撞检测优化：

空间分割（如四叉树）： 当屏幕上对象（子弹、敌机）数量非常多时，可以使用四叉树等空间分割数据结构，将O(N^2)的暴力碰撞检测优化到O(N log N)，避免对所有不相关的对象进行检测。

游戏平衡性：

难度曲线： 设计一个合理的难度曲线函数，使敌机的生成频率、血量和攻击性随游戏进程平滑增长，给玩家带来持续的挑战而非挫败感。

4. 关键技术栈
开发框架： Qt

编程语言： C++

核心Qt模块： QtWidgets, QtGui (包含QPainter, QGraphicsView框架), QtCore, QtMultimedia (用于音效)
